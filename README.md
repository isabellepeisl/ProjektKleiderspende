Kleiderspende: Website zur Organisation von Kleiderspenden
Projektkontext
Dieses Projekt entstand als Fallstudie im Rahmen des Kurses Programmierung von Webanwendungsoberflächen (Aufgabenstellung 3: Kleiderspendenregistrierung). Im Rahmen der Aufgabenstellung sollte eine Website für einen Verein zur Organisation von Kleiderspenden konzipiert und umgesetzt werden. Die Idee des Vereins ist es, dass Nutzer:innen selbst auswählen können, in welches Krisengebiet ihre Kleidung gespendet werden soll. Die Kleidung kann entweder an der Geschäftsstelle des Vereins abgegeben oder durch eine gebuchte Abholung mit einem Sammelfahrzeug des Vereins übergeben werden. Außerdem sollte es möglich sein, die Kleiderspende online zu registrieren. Die Website sollte responsiv sein, also unabhängig von Bildschirmgröße und Endgerät optimal funktionieren.
Umsetzung
Zu Beginn wurden alle notwendigen Elemente und Funktionen der Website identifiziert und der Aufbau bzw. die Architektur festgelegt. Anschließend wurde die Website umgesetzt und die Responsivität immer wieder mit den Entwickler-Tools des Browsers getestet.
Umgesetzt wurden unter anderem:
Mehrseitige Website mit klarer Navigationsstruktur (Home, Aktuelle Krisengebiete, Registrierung, Häufige Fragen, Kontakt & Öffnungszeiten)
Auswahl des Krisengebiets, in das die Kleidung gespendet werden soll
Abgabe der Kleidung an der Geschäftsstelle oder Buchung einer Abholung durch ein Sammelfahrzeug
Online-Registrierung der Kleiderspende
Responsives Layout für Desktop und Mobilgeräte
Impressum und Datenschutzseite
Verwendete Technologien
HTML5, CSS, JavaScript, Bootstrap, Vue.js
Entwicklungsumgebung: Visual Studio Code
